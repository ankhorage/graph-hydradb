# Local acceptance

The pinned HydraDB v0.5.0 image is `ghcr.io/hydra-db/hydradb@sha256:6edb164cfe06015443bbc67003c68ee5e04e42b2d4f088779867ff1654b9bc0b`.

Use the upstream `USING-HYDRADB.md` local development environment values and configure the adapter with loopback HTTP explicitly enabled. The provider token is server-side configuration, never an environment lookup by this package.
